# 풍상 조사 범위

v6.9.2는 가까운 사업장부터 조사할 수 있도록 기본 추적시간을 5분에서 2분으로, 최대 거리를 1,500m에서 300m로 변경합니다. 이는 제품의 조사 범위 기본값이며 대기오염물질의 실제 이동 한계나 검증된 확산거리가 아닙니다. 최대 거리 선택에서 300m·500m·1km·1.5km를 고를 수 있습니다.

3m/s에서는 2분 이동거리 360m를 기본 상한 300m로 제한합니다. 약풍 0.2m/s에서는 최소 조사 거리 50m를 사용합니다. 최대 거리 선택은 사용자가 조사 범위를 조정하는 설정이며 물리적 도달거리의 상한은 아닙니다.

## 거리와 각도

- 자동 거리: `R = round(min(최대 조사 거리, max(50, 풍속 × 추적시간 × 60)))`
- 수동 거리도 선택한 최대 조사 거리 이내로 제한합니다.
- 풍속이 0보다 크면 약풍도 입력 풍향으로 방향 추적과 후보 판정을 수행합니다. 풍속 0, 음수, 유효하지 않은 풍향·풍속만 제외합니다. 중첩 모드에서는 제외 지점 수를 표시합니다.
- 기존 안정도별 각도 σθ: A 25°, B 20°, C 15°, D 10°, E 7.5°, F 5°.
- 기존 자동 풍속 보정: `clamp((2/풍속)^0.35, 0.7, 2.5)`를 σθ에 곱하고 최대 45°로 제한합니다. 수동 거리 모드는 안정도 각도를 그대로 사용합니다.
- 외곽 반각: `min(85°, 2σθ)`. 후보는 측정점에서 거리 5m 이상 R 이내이며 이 각도 안에 있는 사업장입니다.

자동 풍속 보정과 안정도 각도는 기존 앱의 경험적 가정입니다. 관측한 풍향 변동의 표준편차와 동일한 값으로 해석하지 않습니다. [EPA의 기상관측 품질 지침](https://www.epa.gov/sites/default/files/2021-04/documents/volume_iv_meteorological_measurements.pdf)에서 설명하는 σθ는 실제 풍향 시계열로 계산하는 통계량입니다. 위 기본 시간·거리나 계수를 해당 지침의 권고값으로 주장하지 않습니다.

## 그림과 후보의 일치

기존 플룸은 끝부분이 R 바깥으로 돌출되고 후보는 R 안에서만 골라 화면과 판정이 달랐습니다. 이제 두 표시 형태는 동일한 외곽 반각과 반경으로 그립니다. ‘단계 표시’는 같은 외곽 안에 좁은 방향대를 추가하며, 농도 등고선이나 확률 구간을 의미하지 않습니다. 단일 지점과 중첩 분석이 같은 판정 함수를 사용합니다.

조건 JSON에는 `trackingPolicy`, `maximumInvestigationDistanceM`, `minimumWindSpeedExclusiveMs`, `trackingStatus`, `envelopeDefinition`을 기록합니다. 따라서 이전 5분·1,500m 기본값으로 만든 결과와 조건을 구분할 수 있습니다. 원본 측정값과 사업장 자료는 변경하지 않습니다.

현장점검 보고서의 지도에서는 이 조사 범위와 방향선, 후보 강조를 제외합니다. 일반 지도 PNG/SVG와 분석 보고서는 분석 범위를 계속 포함합니다.
