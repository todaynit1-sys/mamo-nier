# MAMO 연구용 작업 화면

## 화면과 사용 흐름

지역과 측정 파일을 준비한 뒤 `분석 → 사업장 → 결과 저장` 패널을 사용합니다. 접힌 설정은 Enter/Space로 열고, 패널은 좌우 방향키로 전환할 수 있습니다. 작은 화면에서는 지도 아래로 스크롤해 설정과 결과 저장에 접근합니다. 지도에는 축척과 북쪽 방향이 표시되며 배경 단순화와 지도 확장 보기를 제공합니다.

`예시 데이터로 둘러보기`는 **가상 측정값**입니다. 실제 내장 사업장 근처에 기능 설명용 측정 지점을 생성합니다. 화면, 그림, 표, 조건 기록, 보고서에 가상 자료 여부를 남깁니다. 실제 측정 결과나 타당성 검증 자료로 사용하지 않습니다.

## 논문 자료 저장

같은 분석 상태에서 다음 자료를 저장하고 원본 측정 파일과 함께 보관합니다.

| 저장 자료 | 포함 내용 |
|---|---|
| 지도 PNG | 현재 지도 범위, 분석 도형, 측정값 색상, 후보, 범례, 축척, 북쪽, 출처와 해석 한계 |
| 지도 SVG | 분석 도형과 글자를 벡터로 저장; 배경지도는 현재 화면 래스터 타일 |
| 후보 CSV | 분석 후보 전체; 단일 지점은 거리·방위각·0–100 후보 점수, 중첩은 최근접 거리·중첩 지점 수 |
| 측정값 CSV | 파서 반영 측정값, 선택 성분·단위, 지점별 적용 바람, 가상 자료 표시 |
| 조건 JSON | 원본 파일 SHA-256, 분석 조건, 필터, 좌표계·범위, 입력 자료 처리 기록, 출처와 한계 |
| 사용 절차 HTML | 입력 열, 처리 흐름, 구현 방법 설명, 현재 조건과 해석 경계 |
| 보고서 미리보기 / PDF | 지도, 농도 그래프, 조건, 후보 전체 표, 출처와 한계; 브라우저 인쇄에서 PDF로 저장 |

PNG 배율은 출력 크기입니다. 현재 화면 타일을 확대하며 새 공간 해상도를 확보한다는 뜻이 아닙니다. SVG를 편집할 때 글꼴과 범례·축척·출처를 유지합니다. 지도 화면의 사업장은 최대 600개로 제한되지만 후보 표는 현재 분석 결과 전체를 저장합니다.

날짜·장비·사업장 자료 기준일을 추정하지 않습니다. 파일에 날짜가 없으면 결과 저장 패널에서 조사 일시를 입력하고, 확인되지 않은 내장 사업장 자료 기준일은 `미기록`으로 남깁니다. 보고서 생성 시각은 한국 표준시로 표시하고 JSON은 ISO 8601로 보관합니다. 조건 JSON에는 분석 엔진·내장 사업장·연구 UI의 SHA-256도 기록합니다. 사용자 사업장 파일을 불러오면 내장 자료와 구별해 파일명·원본 SHA-256·로드 기록을 남깁니다.

## 분석 방법과 보존 범위

기존 VOC 파일 파서, 15개 지역 내장 사업장, 기상 조회, 좌표 변환, 풍상 범위·가우시안 형상·부채꼴 형상·풍속 보정·백분위 계산·후보 점수·중첩 계산을 유지합니다. UI와 저장 기능은 이 값을 기록하고 설명합니다.

고농도 기준은 측정값 내부 백분위이며 법정 기준이 아닙니다. 후보 점수는 풍향 일치도와 거리의 가중 점수이며 확률·배출 기여율이 아닙니다. 중첩 결과에 단일 지점의 방위각이나 임의의 0° 방향을 출력하지 않습니다.

기존 파서는 개별 성분 빈값·비수치를 0으로 처리하고 TVOC 빈값·비수치를 성분 합으로 대체합니다. 처리 건수를 화면·JSON·보고서에 기록합니다. 빈값을 실제 측정 0으로 해석하지 않도록 원본 자료를 먼저 확인해야 합니다. 앱의 간이 스크리닝은 정식 확산모델 검증이나 측정 장비의 품질관리를 대신하지 않습니다.

## 유지보수와 배포

기존 분석 엔진은 `index.html`, 연구용 UI는 `src/research.js`, 스타일은 `src/research.css`에 있습니다. 현재 화면에 필요한 변경을 저장소의 기존 파란색·중립색 체계에서 적용했습니다. 새로운 브랜드 디자인 시스템이나 과학적 검증 승인을 선언하지 않습니다.

```text
npm ci
npm run build
npm run dev
```

Vercel은 `dist`만 게시합니다. 빌드는 해시가 있는 압축 JS와 두 HTML 진입 파일을 만들고 소스맵을 생성하지 않습니다. 개발 파일·설계 메모·검증 캡처는 배포 출력에 넣지 않습니다. 이 저장소는 공개되어 있으므로 GitHub의 개발 원본은 볼 수 있습니다.
