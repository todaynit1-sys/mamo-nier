## 반영 방법

1. 경기도청 목록을 기준으로 삼고 유효한 도청 WGS84 좌표를 우선 적용합니다. 도청 좌표 18,472행이 유효합니다.
2. 도청 좌표가 누락된 885행 중 **사업장명과 도로명 또는 지번주소가 모두 일치**하고 행안부 유효 좌표가 하나로 확정되는 59행만 보완합니다. 이름만 같은 곳이나 주소만 같은 다른 사업장의 좌표를 복사하지 않습니다.
3. 명칭은 법인 표기·공백 등을, 주소는 선행 경기도·괄호 주석·공백·번지 표기를 정리합니다. 도로명 건물번호, 호수, 지번과 지점명은 유지합니다. 유사도 매칭이나 외부 지오코딩을 사용하지 않습니다.
4. 동일한 표시 정보(명칭·좌표·종별·업종·주소)를 가진 중복 **565행**을 제거합니다. 좌표가 같아도 다른 명칭이나 종별이면 유지합니다.
5. 좌표를 확정하지 못한 **826행**은 지도·후보 분석에서 제외합니다. 제외 원본 행과 사유는 manifest에 보관합니다. 행은 CSV 헤더를 1행으로 보는 레코드 순번이며, 따옴표 안 줄바꿈을 포함한 텍스트의 물리적 줄 번호와는 다를 수 있습니다.

최종 지도 대상은 **17,966개**입니다. 도청 좌표 17,907개와 행안부 보완 좌표 59개로 구성됩니다. 도청 목록 밖 행안부 사업장은 이전·변경·중복 여부를 판별할 수 없어 추가하지 않습니다. 다른 시·도 데이터와 분석 계산식은 변경하지 않습니다.

## 출처 간 차이와 정확도

두 자료가 동일명·동일주소로 매칭되더라도 좌표가 다를 수 있습니다. 지도 대상 중 **312개**는 두 출처 사이 거리가 100m를 초과합니다. 이 경우 도청 좌표를 유지하고 사업장 좌표 정확도 항목에 차이와 현장 확인 필요를 표시합니다. 두 좌표의 평균을 내거나 한쪽을 임의 보정하지 않습니다.

좌표 형식이 올바르다고 실제 위치가 정확한 것은 아닙니다. `원본 WGS84 · 정확도 미검증` 또는 `EPSG:5174→4326 변환 · 정확도 미검증`으로 구분합니다. 입력 좌표는 위도 36.8–38.35, 경도 126.3–127.95의 점검 범위로 검사합니다. 이 범위는 행정경계 검증을 대신하지 않습니다. 거리 차이는 반경 6,371,008.8m의 구면 거리이며 소수 첫째 자리 m로 기록합니다.

행안부 좌표계는 [LOCALDATA 공식 안내](https://www.localdata.go.kr/devcenter/bbs/devQnaDetail.do?bbsId=B0000100&menuNo=20003&nttId=1662&pageIndex=1&searchCnd=1&searchWrd=%EC%A2%8C%ED%91%9C)의 중부원점 TM(EPSG:5174)에 따라 변환합니다. 변환은 `pyproj==3.7.2`의 `Transformer.from_crs(5174, 4326, always_xy=True)`를 사용합니다. 도청 WGS84 값은 재변환하거나 임의로 반올림하지 않습니다.

## 분석 기록과 갱신

- 후보 CSV: 사업장 좌표 출처, 도청 원본 행, 행안부 보완 행, 출처 간 좌표 차이, 반영일을 추가합니다.
- 조건 JSON·보고서: 자료 출처·좌표 처리 정책·원본 SHA-256·건수와 반영일을 기록합니다. 사용자 업로드 사업장과 다른 지역에 이 출처를 잘못 붙이지 않습니다.
- [manifest](gyeonggi-facilities-manifest.json): 원본 파일명·SHA-256·인코딩·건수·제외 기록을 보관합니다. 대표자명·사업자번호·전화번호는 앱 데이터에 추가하지 않습니다.

유지보수자는 Python 환경에 `pyproj==3.7.2`를 설치한 후 실행합니다. 원본 CSV를 덮어쓰거나 저장소에 복사하지 않습니다.

```text
python scripts/update-gyeonggi-facilities.py --province <도청.csv> --mois <행안부.csv> --applied-date YYYY-MM-DD
python -m unittest discover -s tests -p test_*.py
node --test tests/*.test.mjs
npm run build
```

스크립트는 경기도 내장 목록과 manifest만 교체합니다. 빌드에서 배포용 HTML과 기존 호환용 HTML을 동기화합니다.
