# 현장점검 보고서

mamo-vocs2의 현장점검 보고서 구성을 mamo-nier에 추가했습니다. 참조 버전은 `todaynit1-sys/mamo-vocs2`의 `ff31419276d288177e34ec289a3d2b5805e1d981`입니다.

## 작성과 저장

1. 측정 파일을 열고 지도 범위·분석 모드·풍상 추적 조건을 맞춥니다.
2. 분석 패널의 배출원 후보 위 **현장점검 보고서 · Word** 또는 결과 저장 패널의 **현장점검 보고서 열기**를 누릅니다.
3. 산업단지 명·측정일자·측정자·특이사항을 확인하거나 입력합니다. 소속은 로그인 기관명으로 고정됩니다. 수도권대기환경청(마스터 포함)은 환경연구사 신현준·전문연구원 서현정을 고정 사용합니다. 다른 기관은 직급·성명이 비어 있어 직접 입력할 수 있습니다.
4. 입력을 바꿨다면 **미리보기 갱신**을 누릅니다. 이전 미리보기로 저장하는 것을 막기 위해 갱신 전에는 저장 버튼이 비활성화됩니다.
5. **Word(.docx) 저장**으로 편집 가능한 Word 파일을 받거나 **인쇄 · PDF**로 브라우저 인쇄 창을 엽니다.

보고서 입력은 현재 브라우저 탭에만 보관합니다. 측정자 성명과 특이사항을 서버에 전송하거나 자동 저장하지 않습니다. 탭을 닫기 전에 필요한 파일을 저장하세요. 새 측정 파일을 열면 측정 구역·측정일자·특이사항은 새 파일 기준으로 다시 준비합니다.

## 문서 구성

- 첫 페이지: 측정정보, 측정자 2명, 현재 범위의 측정점·사업장 지도, 특이사항
- ‘장비 및 자료’ 행은 미리보기·인쇄/PDF·Word 모두 출력하지 않습니다.
- 두 번째 페이지: 항목별 단위·평균·표본표준편차·최댓값
- 기본 구성은 A4 2쪽입니다. 긴 특이사항이나 많은 측정항목은 추가 쪽으로 이어집니다. Word와 브라우저의 글꼴·인쇄 설정에 따라 쪽 배치가 다를 수 있습니다.

지도는 가로세로 비율을 보존한 PNG로 문서 안에 포함합니다. 영향권 도형·방향선·후보 강조는 이 보고서 지도에서 제외합니다. 지역·바람 출처·입력 파일명·버전·분석 시각·저장 안내·해석 한계 문구는 보고서 본문에 출력하지 않습니다. 배경지도의 저작권 표시는 이미지 오른쪽 아래에 유지합니다. 문서 본문과 표는 Word에서 편집할 수 있습니다. OOXML 문서·이미지·스타일을 실제 `.docx` ZIP 패키지로 저장하며 HTML 파일의 확장자를 바꾸는 방식을 사용하지 않습니다. 생성에는 새 CDN이나 외부 문서 변환 서비스를 사용하지 않습니다.

## 값과 출처

- 통계는 원본 유효 좌표 전체 지점의 앱 파서 반영 성분 농도로 계산합니다. 0은 포함하고 비수치·미기록 값은 통계에서 제외합니다. 기존 파서가 빈값을 0으로 바꾼 경우 그 값과 처리 안내를 유지합니다.
- 표준편차는 표본식 `sqrt(Σ(x−평균)²/(N−1))`입니다. 유효 N이 2보다 작으면 표준편차는 ‘미기록’입니다.
- VOC처럼 단위가 모두 같은 경우 평균 순으로 표시합니다. PM·복합 자료처럼 단위가 다른 항목은 숫자로 순위를 매기지 않고 입력 항목 순서를 유지합니다.
- OFP 모드에서는 지도에 OFP 상대지수를 표시하고 표에는 원본 성분 농도를 기록합니다. 원본 농도표를 OFP 합계나 실제 오존 농도로 표시하지 않습니다.
- 파일 날짜를 읽지 못하면 오늘 날짜를 대신 넣지 않습니다. 자동 설정되지 않고 입력하지 않은 측정일자·직급·성명은 ‘미기록’입니다. 산업단지 명의 파일명 제안은 사용자가 확인해야 합니다.
- 가상 예시 자료의 문서에는 실제 관측·점검 결과가 아니라는 표시와 `SAMPLE` 파일명 접두어가 붙습니다.
- 미리보기와 Word는 같은 고정된 보고서 모델과 지도 이미지를 사용합니다. 미리보기를 만든 뒤 다른 분석 상태를 섞어 저장하지 않습니다.

기존 연구 자료 ZIP과 분석 보고서 기능은 그대로 유지됩니다. 현장점검 Word 문서는 해당 작성 화면에서 별도로 저장합니다.

기관을 바꾸어 로그인하면 이전 측정자 입력·특이사항·보고서 미리보기를 지웁니다. 기관 코드는 mamo-vocs2의 위 참조 버전과 같고, 기관 정보는 보고서 소속을 지정합니다. 지도 지역 선택은 기존 방식을 유지합니다.

접속 코드 값은 GitHub와 클라이언트 파일에 넣지 않고 Vercel의 비공개 서버 환경변수 `MAMO_INSTITUTION_CODES`에서 검증합니다. 브라우저는 `/api/institution`에 POST로 확인하고 기관 프로필만 받으며, 코드 값을 저장하지 않습니다. 서버 환경변수가 없으면 접속을 허용하지 않습니다.
## 고농도 위치 기본 문구

현장점검 보고서를 열거나 미리보기를 갱신하면 현재 선택 성분·고농도 기준(기본 상위 10%)으로 지점을 선정합니다. 기본 문구는 ‘경기도 ○○시 ○○로 ○○ 부근 고농도 측정지점 확인’처럼 위치와 확인 문구만 작성합니다. 비율·농도·지점 수·성분·해석은 자동 문구에 넣지 않고 담당자가 작성합니다. 임계값과 같은 값은 포함하므로 동률이 많으면 지점 비율이 10%를 넘을 수 있습니다. 모든 값이 같거나 양수 측정값이 없으면 고농도 문구를 만들지 않습니다.

고농도 지점을 높은 측정값부터 150m 이내로 묶고, 최대 3개 묶음의 대표 측정 좌표만 `/api/address`를 통해 Photon에 조회합니다. 전체 경로·농도·성명·파일·특이사항은 보내지 않습니다. 조회 주소는 인근 OpenStreetMap 주소이며 공적 도로명주소 인증 결과가 아닙니다. 같은 주소는 한 번만 표시하고, 주소 조회 실패 시 ‘주소 미확인 지점 고농도 측정지점 확인’으로 표시합니다. 보고서 작성 화면에 출처를 표시합니다.

각 대표 좌표당 주소 후보를 최대 10개 받아, 확인된 도로와 일치하며 좌표에서 75m 이내인 가장 가까운 건물번호 포함 주소를 우선 표시합니다(예: ‘경기도 ○○시 만세로 123 부근 고농도 측정지점 확인’). 다른 도로·75m 초과·좌표 없는 후보의 건물번호를 붙이지 않습니다. 번호가 없으면 확인된 도로명·지역만 사용하며, 번호를 추정하거나 보간하지 않습니다. 이동측정 지점 자체의 공적 건물 주소를 인증하는 기능은 아닙니다.

직접 편집하거나 지운 특이사항은 갱신·성분 변경·창 재열기 시 보존합니다. 새 측정 파일 또는 다른 기관으로 전환하면 초기화합니다. 기본 문구와 최종 수정 내용은 같은 미리보기와 Word 파일에 반영됩니다.

주소 조회는 보고서를 여는 사용자 동작에만 실행하며, 탭 내 결과 재사용·서버 메모리 캐시·순차 요청·요청 시간 제한을 적용합니다. Photon 공개 서버는 가용성을 보장하지 않습니다. 사용량이 늘면 `MAMO_PHOTON_URL` 서버 환경변수로 자체 Photon 역지오코딩 서버를 지정할 수 있습니다. [Photon 이용 안내](https://github.com/komoot/photon#demo-server), [주소 조회 API](https://github.com/komoot/photon/blob/master/docs/api-v1.md#reverse).
