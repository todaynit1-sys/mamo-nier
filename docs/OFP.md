# OFP 상대지수 모드

성분별 VOC(ppb) 파일을 연 뒤 **분석 → 분석 모드 → OFP 상대지수 · MIR 가중**을 선택합니다. 지도 색상, 평균·최대, 지점 선택, 고농도 백분위와 풍상 중첩 분석이 같은 지수를 사용합니다. 측정 농도로 돌아가면 원래 성분 농도와 전체 유효 좌표 지점을 복원합니다.

## 가져온 계수와 계산

- 계수: [mamo-oz assets/app.js](https://github.com/todaynit1-sys/mamo-oz/blob/7e8ce1c72bf43093257cde0cbb8c0776a8d64149/assets/app.js)의 MIR 41개를 값 변경 없이 사용합니다.
- 원본 commit: `7e8ce1c72bf43093257cde0cbb8c0776a8d64149`; Git blob: `4aa6f41fb6ba2749cced32ca284956d72bb46be3`.
- 계산: `OFP 상대지수 = Σ [매칭된 성분 농도(ppb) × 해당 MIR]`.
- 예: Benzene 10 ppb, Toluene 20 ppb이면 `10 × 0.72 + 20 × 4 = 87.2 ppb·MIR`입니다.

이는 mamo-oz의 ppb × MIR 방식을 비교용 지수로 확장한 것입니다. MIR은 질량 기준 `g O₃/g VOC` 계수이므로 ppb에 직접 곱한 합을 질량 기반 OFP(µg O₃/m³)나 오존 농도(ppb)로 표시하지 않습니다. 질량 기반 계산에는 성분별 분자량과 기체 상태 조건, 혼합 성분의 조성 확인이 추가로 필요합니다. 원본의 혼합 성분 계수는 개별 성분의 공인 계수라고 주장하지 않습니다. 참고: [CARB MIR 자료](https://www.arb.ca.gov/regact/2009/mir2009/mir2009.htm), [CARB MIR 단위 설명](https://ww2.arb.ca.gov/sites/default/files/classic/research/apr/reports/l825.pdf).

## 매칭과 제외

대소문자·공백·유니코드 하이픈을 정규화하고 `1,3-butadiene`은 원본의 `1.3-butadiene`에 연결합니다. 그 외에 다른 성분이나 이성질체의 계수를 추정하지 않습니다. 예를 들어 `ethylbenzene+xylene`은 묶음 이름 전체에만 적용하고 개별 ethylbenzene·m/p-xylene에는 대입하지 않습니다.

TVOC는 합산하지 않습니다. 미등록 성분, ppb가 아닌 성분, 같은 MIR 키에 중복 매칭된 열은 제외하며 화면·조건 JSON·보고서에 처리 사유를 남깁니다. 미등록 성분이 있으면 결과는 매칭된 성분 범위의 부분 지수입니다. 서로 다른 자료를 비교할 때 매칭 성분 목록과 유효 지점의 차이부터 확인해야 합니다.

매칭 성분에 빈값·비수치·음수가 하나라도 있는 지점은 OFP 모드에서 제외합니다. 원본 CSV 행과 좌표를 확인해 기존 농도 파서가 빈값을 0으로 대체한 결과를 OFP에서 실제 0으로 오인하지 않도록 합니다. 실제 측정 0은 유효합니다. 매칭 성분 또는 유효 지점이 없으면 모드를 사용할 수 없습니다. PM 파일에는 적용하지 않습니다.

## 저장과 해석

- OFP 계산 내역 CSV: 원본 유효 좌표 지점 전체의 성분 농도, MIR 키·계수, 성분 기여, 지점 합계와 제외 사유를 기록합니다. 제외 지점의 합계는 빈칸입니다.
- 측정값 CSV: 현재 분석에 사용한 지점과 선택 분석값·단위, 기존 성분별 파서 반영값을 기록합니다.
- 조건 JSON: 분석 지표, 원본 계수 버전, 성분 매칭, 유효·제외 지점 수, 처리 정책, 성분별 평균 기여·지수 내 비율을 포함합니다.
- PNG/SVG: 지수 단위와 상대지수 해석 경계를 표시합니다.
- 보고서/사용 절차 HTML: 매칭·계수·처리 내역·성분별 지수 기여를 포함합니다. 기존 인쇄/PDF 기능을 사용합니다.
- ZIP: 기존 8개 자료에 매칭 성분이 있으면 `ofp.csv`를 추가합니다. 현재 지도와 계산 조건을 동일한 상태로 보관합니다.

성분별 비율은 계산된 지수 내 비율입니다. 오존 생성 기여율이나 사업장 배출 기여율이 아닙니다. 고농도 백분위는 OFP 유효 지점 내부 분류이며 관측 O₃ 초과 판단이나 광화학 체제 판정이 아닙니다. 사업장 후보는 기존 풍상 범위 스크리닝 결과입니다.
