# MAMO · AI 기반 대기오염물질 분석시스템 (전국 광역)

v6.10 연구용 작업 화면: 분석·사업장·결과 저장 패널, 가상 예시와 CSV 양식, 지도 PNG/SVG, 후보·측정값 CSV, 조건 JSON, 사용 절차 HTML, 지도와 분석 조건을 포함한 PDF 보고서 미리보기를 제공합니다. **연구 자료 ZIP 저장**으로 같은 분석 상태의 모든 자료와 오프라인 보고서를 한 번에 보관할 수 있습니다. 측정 지점 선택·이전/다음·최고 농도 이동과 입력 자료 처리 내역을 분석 패널에서 확인할 수 있습니다. 사용 방법과 자료의 의미는 [연구용 UI 안내](docs/RESEARCH-UI.md)를 참고하세요.

고농도 분류 기본값은 상위 10%(90백분위)이며, 풍상 추적 설정과 배출원 후보를 분석 패널 맨 위에 배치합니다. 지도 상단에서 성분·농도/OFP·고농도 중첩을 바로 바꿉니다. 바람 설정 바로가기를 제공하며, 모바일에서는 지도와 내부 스크롤 설정 패널을 함께 유지합니다.

mamo-oz의 MIR 41개를 적용한 **OFP 상대지수 모드**를 지원합니다. 성분 매칭·지수 계산·단위와 저장 방법은 [OFP 안내](docs/OFP.md)를 참고하세요.

Vercel 배포는 `npm run build` 결과인 `dist`를 게시합니다. 로컬 개발은 `npm ci`, `npm run build`, `npm run dev` 순서로 실행하며 `http://127.0.0.1:8766`에서 확인합니다.

이동측정(VOC·성분) 데이터로 대기오염 배출원을 **바람 상류(풍상)로 역추적**하고, 그 범위에 드는 전국 대기배출사업장을 후보로 제시해 인쇄용 분석보고서를 만드는 **정적 분석 화면과 기상청 조회 서버로 구성된 웹 앱**입니다. 이용자는 별도 설치 없이 배포 주소에서 실행합니다.

> **제작 · 관리: 신현준 (수도권대기환경청)**
> 내부 업무용 도구입니다.

## 핵심 기능

- **이동측정 데이터 표출** — 측정 CSV·TXT·XLSX(성분별 ppb, No./시각/좌표)를 자동 인식해 지도에 농도별로 표시
- **풍상 확산 추적** — 측정 지점에서 바람이 불어온 쪽으로 거리·각도 경계 안의 풍상 조사 범위를 표시합니다. 기본 2분·최대 300m이며, 0보다 큰 약풍도 입력 풍향으로 추적합니다. 풍속 0 또는 바람 미기록만 방향 추적을 보류합니다. 최대 거리는 300m~1.5km에서 조정할 수 있습니다
- **전국 광역 사업장 내장** — 15개 시·도의 대기배출사업장 **47,240개**를 좌표와 함께 내장(인터넷 없이 즉시 표출). 지역 드롭다운으로 전환
- **업종·종별 필터** — 측정 오염물질에 맞는 업종(도장·화학·도금 등)·종별(1~5종)로 후보를 좁힘
- **상류 중첩 분석** — 여러 고농도 지점의 풍상 범위가 겹치는 곳을 자동 강조 → 여러 지점이 공통으로 가리키는 유력 배출원 도출
- **기상청 자동 풍향·풍속** — 전국 AWS 398개 지점 좌표 내장, 측정 지점 최근접 관측소에서 자동 조회(벡터 풍향·평균 풍속). 앱의 `/api/kma` 서버가 기상청에 직접 연결하며 공용 CORS 중계를 사용하지 않습니다.
- **사업장 검색 + 지도앱 연동** — 이름·주소 검색, 팝업에서 카카오맵·로드뷰·네이버지도 바로 열기
- **분석 보고서** — 측정 개요·성분 순위·확산 설정·배출원 후보표·한계 고지를 인쇄/PDF로 출력

## 사용법

1. 배포 주소를 브라우저(Chrome 권장)로 엽니다. (접속코드 기본값 `1111`)
2. 배출원 **지역(시·도)** 을 고르고, 이동측정 파일을 드래그해 올립니다.
3. 지도에서 고농도 지점을 클릭하면 풍상 확산 범위와 배출원 후보가 표시됩니다.
   - `🌤 기상청 자동 조회`로 풍향·풍속을 받아오거나 직접 입력합니다.
   - `🎯 상류 중첩 분석`을 켜면 모든 고농도 지점 기준으로 유력 배출원을 강조합니다.
   - 업종·종별 필터로 후보를 좁힙니다.
4. `분석 보고서 내보내기`로 인쇄/PDF 저장.

## GitHub Pages로 배포(선택)

분석 화면을 정적 호스팅할 수 있지만, 기상청 조회에는 Vercel의 `/api/kma` Node.js 함수가 필요합니다. GitHub Pages만으로는 기상청 조회가 동작하지 않으며 파일 내 바람 또는 직접 입력을 사용해야 합니다.

## 현장점검 보고서 (v6.10)

mamo-vocs2의 A4 현장점검 보고서 구성을 추가했습니다. 배출원 후보 위 또는 결과 저장 패널에서 보고서를 열고 측정정보·측정자·특이사항을 입력한 뒤 같은 지도의 미리보기와 Word(.docx)를 저장합니다. 항목별 단위·평균·표본표준편차·최댓값과 OFP 구분을 포함합니다. [작성 방법·통계 정책](docs/FIELD-REPORT.md)을 참고하세요.

## 기상청 연결 개선 (v6.8)

- 고정된 기상청 AWS 주소만 조회하는 서버 경로로 CORS 문제를 해소합니다. 인터넷·인증·응답 지연과 실제 결측을 구분합니다.
- 측정 파일의 연월일·시각을 KST로 조회합니다. 날짜가 없거나 하루를 초과하면 현재 날씨로 대체하거나 기간을 잘라 사용하지 않습니다.
- 1분 평균 WD1/WS1만 사용하며, 결측을 10분 평균 바람 등 다른 평균구간의 값으로 대체하지 않습니다.
- 최근접 2개씩 최대 8개 관측소를 조회합니다. 공통 연결 오류·인증 오류 시 불필요한 추가 요청을 중단하고 기존 바람 값을 유지합니다.
- 파일·바람 설정 변경 시 진행 중 요청을 취소합니다. 성공한 조회만 5분간 메모리에 재사용하며, 관측소·조회 기간·유효 분 수·출처·조회 상태를 조건 JSON과 보고서에 기록합니다.

공식 명세: [기상청 API허브 AWS 매분자료](https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=239), [Vercel Node.js 함수](https://vercel.com/docs/functions/runtimes/node-js).

## 경기도 좌표 갱신 (v6.6)

경기도청 목록·WGS84 좌표를 우선 적용하고 누락 좌표 59개는 동일 사업장명·주소의 행안부 TM 좌표로 보완했습니다. 동일 표시행 565개를 제거한 지도 대상은 17,966개이며 좌표 미확정 826행은 제외했습니다. [갱신 정책·출처·기록](docs/GYEONGGI-FACILITIES.md)을 참고하세요.

## 데이터 출처 · 좌표계

- 경기도 사업장: **경기도청 환경오염물질배출업소현황** (WGS84 우선), 행안부 자료로 누락 좌표만 보완
- 다른 지역 사업장: **환경부 대기오염물질 배출시설 설치사업장** (공공데이터, 중부원점TM **EPSG:5174** → WGS84 변환 내장)
- 기상: **기상청 API허브** AWS 분단위 관측(`nph-aws2_min`) · 지점 좌표 내장

## ⚠️ 한계 고지

이 도구는 **현장 조사 우선순위를 좁히기 위한 스크리닝용**입니다. 풍상 조사 범위는 입력 풍향·안정도 기준의 간이 추정이며, 확산각의 풍속 보정 지수 등은 경험적 단순화입니다. **규제·법적 판단에는 CALPUFF·HYSPLIT 등 정식 확산모델 검증이 필요**합니다. 좌표 없는 사업장 3,700여 건은 제외되었습니다.

## 참고 (내부용)

- 기존 기상청 API허브 인증키는 같은 앱의 서버에 POST로 전달하며 기상청에만 사용합니다. 공용 프록시에 전달하지 않고 응답·조건 파일·오류 문구에도 포함하지 않습니다. 서버 환경 변수 `KMA_API_KEY`를 설정하면 해당 값을 우선 사용합니다. 이번 갱신에서 키를 교체하지 않았습니다.
- 전국 사업장·AWS를 포함하는 자료이므로, 처음 열 때 몇 초 걸릴 수 있습니다.
